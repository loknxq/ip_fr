# Vinyl Collection Service

## Назначение

Приложение для учёта личной коллекции виниловых пластинок. Позволяет
каталогизировать пластинки, распределять их по коллекциям и получать информацию
о содержимом коллекций.

## Целевая аудитория

- Частные коллекционеры винила
- Владельцы небольших музыкальных магазинов
- Меломаны, ведущие учёт своих записей

## Предметная область

Предметная область — учёт музыкальных носителей (виниловых пластинок).
Ключевые понятия: пластинка (издание), коллекция (тематическая подборка),
исполнитель, жанр, год выпуска, состояние пластинки.

## Основные сущности

- Пластинка (id, название)
- Коллекция (id, название, список id пластинок)

## Возможности

- Просмотр списка всех пластинок
- Просмотр списка всех коллекций
- Просмотр содержимого выбранной коллекции
- Добавление новой пластинки в каталог
- Создание новой коллекции с выбором пластинок
- Сохранение и загрузка данных в JSON-файлах

## Структура проекта

- `main.py` — точка запуска, меню приложения;
- `records.py` — работа с пластинками;
- `collections.py` — работа с коллекциями;
- `storage.py` — сохранение и загрузка данных;
- `utils.py` — вспомогательные функции ввода;
- `data/` — JSON-файлы данных;
- `tests/` — автоматизированные тесты.
