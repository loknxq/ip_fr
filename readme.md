# Vinyl Collection Service

## Назначение

Приложение для учёта личной коллекции виниловых пластинок. Позволяет
каталогизировать пластинки, распределять их по коллекциям и получать информацию о содержимом коллекций.

## Целевая аудитория

- Частные коллекционеры винила
- Владельцы небольших музыкальных магазинов
- Меломаны, ведущие учёт своих записей

## Предметная область

Предметная область — учёт музыкальных носителей (виниловых пластинок).
Ключевые понятия: пластинка (издание), коллекция (тематическая подборка),
исполнитель, жанр, год выпуска, состояние пластинки.

## Основные сущности

- Пластинка 
- Коллекция (название, описание, список пластинок)
- Пользователь

## Основные функции

- Просмотр списка всех коллекций
- Просмотр содержимого выбранной коллекции
- Добавление новой пластинки в каталог
- Создание новой коллекции с выбором пластинок
- (в перспективе) Поиск пластинок по исполнителю и жанру

## План развития

На следующих этапах планируется:

- разработка веб-приложения на Django;
- подключение базы данных (PostgreSQL);
- реализация пользователей и аутентификации;
- разработка REST API;
- контейнеризация приложения (Docker);
- настройка CI/CD.
