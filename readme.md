# Vinyl Collection Service (ООП-версия)

## Назначение

Консольное приложение для учёта личной коллекции виниловых пластинок.
Позволяет каталогизировать пластинки, распределять их по коллекциям,
получать информацию о содержимом коллекций и вести список пользователей.

## Предметная область

Основные сущности:
- **Пластинка (Record)** — отдельное музыкальное издание;
- **Коллекция (Collection)** — тематическая подборка пластинок;
- **Пользователь (User)** — владелец коллекции.

## Основные классы

### Record — пластинка
**Атрибуты:** `id`, `title`, `artist`, `genre`, `year`.
**Методы:**
- `display_name` (property) — отображаемое имя;
- `validate_year()` (staticmethod) — проверка года выпуска;
- `from_data()` (classmethod) — создание из словаря;
- `to_data()` — преобразование в словарь;
- `__str__()` — строковое представление.

### Collection — коллекция
**Атрибуты:** `id`, `name`, `records: list[Record]`.
**Методы:**
- `size` (property) — количество пластинок;
- `add_record()` / `remove_record()` — управление составом;
- `from_data()` (classmethod) — создание из словаря с восстановлением связей;
- `to_data()` — сохранение в виде словаря (хранятся только id пластинок);
- `__str__()`.

### User — пользователь
**Атрибуты:** `id`, `name`, `email`.
**Методы:**
- `from_data()` (classmethod);
- `to_data()`;
- `__str__()`.

## Взаимодействие объектов

Коллекция `Collection` содержит ссылки на объекты `Record`:
Collection.records: list[Record]
Это позволяет напрямую обращаться к данным пластинок:
```python
collection.records[0].title
collection.records[0].artist
