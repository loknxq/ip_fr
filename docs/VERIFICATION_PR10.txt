3. ДЕЙСТВИЯ ДЛЯ ЗАВЕРШЕНИЯ ПРОВЕРКИ

В корне ip_fr установите зависимости: python -m pip install -r requirements.txt
Проверьте подготовку реальной БД: python manage.py migrate
Далее: python manage.py check
Далее: python manage.py makemigrations --check --dry-run
Далее: python manage.py showmigrations
Далее: pytest -v
Далее: flake8 . --extend-exclude=venv
Далее: python manage.py demo_pr10
Затем createsuperuser/runserver и реальные скриншоты админки, журнала, SQL-панели, терминала.
Пока эти команды не выполнены в окружении с Django, их успех не подтверждён.
